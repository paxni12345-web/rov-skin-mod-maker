# RoV Skin Mod Generator (Auto Skin Swapper) 🎮🔥

เครื่องมือสร้างมอดสกิน RoV สลับโมเดลเป็นร่างต้น (Full Set + เลือกระบบ 10v10 ได้) สำหรับใช้งานบน Android ผ่าน **Termux** หรือ **Pydroid 3**

## ✨ คุณสมบัติเด่น
- **Full Set Mod:** สลับครบชุดทั้งโมเดล 3D (Mesh/Texture), เอฟเฟกต์สกิล (VFX), ท่าวาร์ป/ท่ายืน (Animation) และเสียงพากย์ (Sound/VO)
- **โหมด 10v10:** มีตัวเลือกถามว่าจะนำไฟล์เอฟเฟกต์ของโหมด 10v10 (Mayhem) ไปด้วยหรือไม่
- **สร้างไฟล์ .zip สำเร็จรูป:** จัดโครงสร้างโฟลเดอร์สำหรับแตกไฟล์ลงในเกมผ่าน **ZArchiver** โดยตรง

---

## 🚀 วิธีใช้งานใน Termux (Android)

### 1. ติดตั้งแพ็กเกจที่จำเป็น
เปิดแอป Termux แล้วพิมพ์คำสั่ง:
```bash
pkg update && pkg install git python -y
termux-setup-storage
```
*(กดยืนยันอนุญาตสิทธิ์เข้าถึงพื้นที่จัดเก็บข้อมูลบนหน้าจอมือถือ)*

### 2. รันสคริปต์ได้ทันที (คำสั่งบรรทัดเดียว)
```bash
python <(curl -sL https://raw.githubusercontent.com/paxni12345-web/rov-skin-mod-maker/main/rov_skin_mod_maker.py)
```

หรือจะ Clone โปรเจกต์ลงเครื่อง:
```bash
git clone https://github.com/paxni12345-web/rov-skin-mod-maker.git
cd rov-skin-mod-maker
python rov_skin_mod_maker.py
```

### 3. กรอกข้อมูลตามที่ระบบถาม
1. **รหัสฮีโร่ (Hero ID):** เช่น `150` (Nakroth), `168` (Florentino), `190` (Airi)
2. **ลำดับสกิน:** เช่น `1`, `2`, `5`, `6`
3. **ติดเอฟเฟกต์ 10v10 ด้วยไหม:** `y` (เอา) หรือ `n` (ไม่เอา)
4. **ติดเสียงพากย์ด้วยไหม:** `y` (เอา) หรือ `n` (ไม่เอา)

## 📦 วิธีนำไฟล์มอดไปลงในเกม RoV
เมื่อสคริปต์ทำงานเสร็จ จะได้ไฟล์ `.zip` อยู่ในโฟลเดอร์ **Download** ของมือถือ:
1. เปิดแอป **ZArchiver**
2. ไปที่โฟลเดอร์ `Download`
3. กดที่ไฟล์ `.zip` ของมอดที่สร้างขึ้น
4. เลือก **แตกไฟล์ที่นี่ (Extract here)**
5. ติ๊กถูกที่ช่อง **นำไปใช้กับทุกไฟล์ (Apply to all)** แล้วกด **แทนที่ (Replace)**
6. เปิดเกม RoV เลือกร่างต้นเพื่อทดสอบได้เลย!
